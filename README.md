# Marine Job Portal 🌊

بوابة وظائف الصيد البحري العالمية (نسخة الأصلية بدون تعديل).

## 🚀 ما هو المشروع؟
بوابة مفتوحة المصدر لعرض وظائف قطاع الصيد البحري حول العالم، تسمح بالتسجيل، نشر الوظائف، والبحث.

## 🔧 كيفية البدء
```bash
git clone https://github.com/YourUser/marine-job-portal.git
cd marine-job-portal
# تشغيل حسب التقنيات المستخدمة:
npm install && npm start
# أو
pip install -r requirements.txt && flask run
